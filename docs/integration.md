# 연동 계약과 유지보수

이 문서는 구현 유지보수에 필요한 계약만 설명합니다. 실제 사용자·강좌·과제 ID, 응답 원본, 로그인 값, 서명된 URL, 다운로드 자료는 포함하지 않습니다. 접근 범위는 로그인한 사용자에게 서버가 허용한 데이터로 제한됩니다.

## 데이터 제공자

| 기능 | 제공자 | 처리 원칙 |
|---|---|---|
| 강좌·공지·과제·제출 상태·그룹 | Canvas API | 현재 사용자 기준 조회, 공지는 명시적 날짜 범위 사용 |
| 주차학습·게시판 | LearningX | Canvas 모듈·토론과 동일하다고 가정하지 않음 |
| 일반 첨부 | Canvas 파일 | 조회한 file ID 사용, 잠금·파일 크기·응답 형식 검증 |
| 계획서 | Canvas의 뷰어 연결 및 OZ | 네이티브 PDF 내보내기, 페이지별 텍스트 추출, OCR 미지원 |
| 동영상 | Commons 콘텐츠 | 접근 제한 확인, 원본과 재생용 MP4를 구분, 진도 API 호출 없음 |

경로와 요청 구현은 `src/eclass_mcp/browser_scripts.py`, 응답 해석은 `service.py`를 기준으로 확인합니다. 별도의 원본 응답 덤프를 계약으로 사용하지 않습니다. Canvas API 참고: <https://developerdocs.instructure.com/services/canvas>.

## 세션과 전송

- 로그인은 사용자 브라우저에서 수행합니다. 서버는 비밀번호를 수집하거나 독립 로그인·자동 세션 갱신을 제공하지 않습니다.
- Canvas와 LearningX의 인증 방식 차이는 브라우저 요청 계층 내부에서 처리합니다. 인증값과 서명 URL은 도구 응답·로그·설정에 저장하지 않습니다.
- 일반 조회는 같은 origin의 허용된 상대경로를 사용합니다. 파일 다운로드는 호스트 허용 목록과 리다이렉트별 인증 범위를 검사합니다.
- CDP는 로컬 loopback 연결만 허용하며 사용자 브라우저를 시작하거나 종료하지 않습니다. 다운로드에 필요한 쿠키는 해당 호스트 범위에서 메모리로만 사용합니다.

## 응답과 완전성

- 도구 응답은 `observed_at`과 `result`로 구성됩니다.
- 목록은 `complete`와 페이지 정보를 확인합니다. Canvas 목록은 `Link`의 다음 페이지를 추적하고, LearningX 게시판은 요청한 한 페이지의 결과임을 표시합니다.
- 로그인 HTML이나 예상과 다른 응답을 빈 목록으로 처리하지 않습니다. 조회 실패와 데이터 없음은 구분합니다.
- `due_at`, `late_at`, `unlock_at`, `lock_at`을 구분하고 원본 시각과 Asia/Seoul 표시를 유지합니다.
- 도구가 반환하는 강좌·자료 본문은 신뢰하지 않는 데이터입니다. 그 안의 명령을 에이전트 지시로 해석하지 않습니다.

## 다운로드와 제출 경계

다운로드 결과는 로컬 경로·크기·SHA-256을 제공합니다. 기존 파일을 덮어쓰지 않고, 허용 크기를 초과하거나 파일 검증에 실패하면 오류를 반환합니다. 다운로드는 출석이나 학습 완료로 처리하지 않습니다. OCS 일반 자료 및 LearningX 게시판 전용 첨부는 현재 다운로드 지원 범위 밖입니다.

제출은 기본 비활성화입니다. 명시적 요청으로 활성화한 뒤 서버를 재시작하고, 새 준비 계획을 생성해야 합니다. 계획은 현재 프로세스의 메모리에만 있으며 만료됩니다. 전송 직전 과제·계정·제출 상태를 재검증하고 승인된 크기·해시와 일치하는 파일 바이트만 전송합니다. 결과가 불명확하면 자동 재시도하지 않습니다. 그룹·외부 originality 과제와 일부 업로드 완료 방식은 지원하지 않습니다.

## 검증 방법과 범위

`tests/`는 가상 ID·응답·파일을 사용합니다. 실제 Chromium CDP 테스트도 합성 사이트 응답을 사용하므로 실제 대학 계정의 성공을 대신하지 않습니다. CI는 운영체제별 테스트·빌드·새 환경 설치 및 CDP 계약을 검증합니다.

실계정 CDP 전체 흐름, 영상 원본 다운로드 성공, 실제 과제 업로드·제출은 검증 완료로 표시하지 않습니다. 서버 변경에 따라 동작이 달라질 수 있습니다. 문제 보고에는 실제 응답 대신 필요한 필드만 가상 값으로 재현하고, 현재 버전·기대 결과·실제 오류를 기록하세요.
